# Beine · Генератор коммерческих предложений

[Открыть редактор](https://adilkhanweb.github.io/cpgen/)

Редактируйте КП прямо на листе: реквизиты, изображения с подписями, таблицы, автоматические итоги и сохранённые блоки. PDF экспортируется одним длинным листом. В публичной версии используется демонстрационный проект без клиентских фотографий и реквизитов.

Фирменный логотип появляется в шапке КП и в PDF. Поля агентства открываются по кнопке **«Изменить реквизиты»** в шапке листа; заполненные значения сохраняются в документе.

Сайт статический. Реквизиты, загруженные фотографии, черновики и библиотека хранятся в браузере (IndexedDB), а не на GitHub. Для переноса с локального редактора скачайте резервную копию в старой версии и откройте её на сайте. Не добавляйте резервные копии, оформленные КП или клиентские фотографии в репозиторий. Храните экспорт отдельно: очистка данных сайта удалит локальный черновик.

## Разработка и проверка

Самостоятельный файл `index.html` содержит весь редактор; для ручного просмотра откройте его в Chrome или Edge. Для автоматических проверок нужен Node.js 24:

```sh
npm ci
npx playwright install chromium
npm test
```

На Linux для новой системы используйте `npx playwright install --with-deps chromium`. Для проверки с установленным Chrome задайте `CPGEN_CHROME` (путь к исполняемому файлу). `CPGEN_URL` позволяет прогнать те же проверки по уже опубликованному адресу; тесты используют отдельный контекст браузера.

GitHub Actions запускает проверки на pull request и при push в `main`. GitHub Pages получает только `index.html` после успешных проверок на `main`. Источник Pages — **GitHub Actions**, окружение — `github-pages`. Для отката отмените проблемный коммит в `main`: workflow проверит и опубликует восстановленную версию.

Лицензии встроенного Montserrat и зависимостей Tiptap/ProseMirror сохранены в `index.html`.
